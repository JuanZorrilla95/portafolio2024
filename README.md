# Portfolio — Juan Zorrilla Menez

Portfolio personal desarrollado con React, para mostrar mis proyectos y mi trabajo como desarrollador. Live en https://juanz.dev

## Qué resuelve

Necesitaba un espacio propio, sin depender de plataformas de terceros, donde centralizar mis proyectos, mi trayectoria y una forma de contacto directa. Lo pensé también como evidencia de que puedo trabajar con React de forma autónoma: acá el diseño, la arquitectura y el mantenimiento son míos de punta a punta.

## Stack

- **React** (Create React App)
- **Tailwind CSS** — estilos
- **Vercel** — deploy y hosting

## Cómo correrlo

```bash
git clone https://github.com/JuanZorrilla95/portafolio2024.git
cd portafolio2024
npm install
npm start
```

Abre en `http://localhost:3000`.
